# Summerstrand Rooms

Single rooms in four student houses in Summerstrand, Gqeberha, for November to January. R2,500 a month.

- 6 Bradley Road
- 23 Admiralty Way
- 31 Admiralty Way
- 4 Tilbury Road

Visitors pick a house and room, fill in a 3-step form, and the application opens in WhatsApp.

## Editing
All details (price, dates, rooms, what's included, rules) are in the settings block near the bottom of `index.html`.
To mark a room as booked, change `{ n: 2 }` to `{ n: 2, taken: true }`.
